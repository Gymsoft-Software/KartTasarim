# Kart Görselleri

[← Depo tanıtımı](../README.md) · [Kart kataloğu kullanım rehberi](../docs/kart-tasarim/KULLANIM_REHBERI.md)

Bu klasör, kart kataloğunda listelenecek kaynak görselleri içerir. Dosyalar GitHub API üzerinden alınır; katalog yalnızca bu klasörün doğrudan içindeki görselleri okur.

- Desteklenen biçimler: PNG, JPG, JPEG, WEBP, GIF ve AVIF.
- Ön ve arka yüzleri ayrı, anlaşılır adlarla ekleyin: `ornek ön.png`, `ornek arka.png`.
- Arayüzün önerdiği görsel ölçüsü 525 × 824 pikseldir; bu bir baskı ölçüsü tanımı değildir.
- Dosyayı `main` dalına ekledikten sonra katalogda **Yenile** düğmesini kullanın.
- Rehber ekran görüntülerini buraya eklemeyin; aksi halde kart olarak listelenirler. Bu görseller `docs/` altında tutulur.

Katalog ayarları [assets/kart-tasarim/config.js](../assets/kart-tasarim/config.js) dosyasındadır. Bu README bir görsel olmadığı için katalogda listelenmez.
